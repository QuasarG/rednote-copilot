# Asset placeholders for README

Add your final screenshots / diagrams / videos here, then update the paths in `README.md`.

Expected files:

- `hero-screenshot-light.png` — light-mode hero banner / app screenshot
- `hero-screenshot-dark.png` — dark-mode hero banner / app screenshot (optional)
- `demo-video.mp4` — demo video, then replace the GitHub video link in README
- `agent-workflow.png` — agent graph visualization
- `project-timeline.png` — project-level workflow / timeline diagram
- `workbench-screenshot.png` — Flask workbench screenshot

You can also use a single `hero-screenshot.png` and remove the `<picture>` element if you only have one hero asset.
